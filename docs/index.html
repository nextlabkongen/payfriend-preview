Hurtig start

Kom i gang p\u00e5 f\u00e5 minutter

Opret et API-token, send din f\u00f8rste foresp\u00f8rgsel, og begynd at bygge.

1

Opret et token

Gå til Indstillinger → Integrationer i Payfriend-dashboardet. Opret et token med de rettigheder du har brug for.

2

Send en forespørgsel

Brug dit token som Bearer-token i Authorization-headeren. Alle endpoints returnerer JSON.

3

Byg din integration

Brug REST API’et til custom integrationer, eller MCP-serveren til at lade AI-agenter styre dine workflows.

Autentificering

Token-baseret adgang

Alle API-kald kræver et token. REST API bruger Authorization: Bearer, mens MCP-endpoints bruger X-MCP-Token. Opret tokens under Indstillinger → Integrationer.

Afgrænsede rettigheder — opret skrivebeskyttede eller fuld-adgang tokens

SHA-256 hashed — token-værdier gemmes aldrig i klartekst

Valgfri udløbsdato — tilbagekald når som helst fra dashboardet

Token-rettigheder

customers:read / customers:writeLæs og administrér kunder
invoices:read / invoices:writeLæs og administrér fakturaer
payments:read / payments:writeLæs og registrér betalinger
flows:read / flows:writeLæs og administrér inkassoflows
mcp:accessAdgang til MCP-endpoints
*Fuld adgang (alle rettigheder)
REST API
curl -X GET https://app.payfriend.io/api/v1/customers \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Accept: application/json"
MCP Endpoint
curl -X POST https://app.payfriend.io/mcp/v1/customers/list \
  -H "X-MCP-Token: YOUR_TOKEN" \
  -H "Content-Type: application/json"
